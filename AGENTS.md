# UI/UX Pro Max : Contrôle Qualité Obligatoire
À chaque création ou modification d'interface dans ce projet, appliquer rigoureusement le skill `ui-ux-pro-max` :
- Vérifier l'accessibilité (contraste WCAG AA 4.5:1, zones tactiles min 44px, navigation clavier).
- Profondeur visuelle & esthétique premium (pas de designs plats sans vie).
- Micro-interactions et états interactifs complets (default, hover, active, disabled).
- Cohérence du design system (grille 8px, typographie hiérarchisée, tokens de couleurs sémantiques).
- Responsive mobile-first sans débordement horizontal.
